# Exercise 01: Linux Filesystem Navigation

## Objective

Practise navigating the Linux filesystem and inspecting files and directories using basic command-line tools.

## Commands

| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `ls -la` | List entries, including hidden files, with detailed information |
| `cd` | Change the current directory |
| `mkdir` | Create a directory |
| `touch` | Create an empty file |
| `cp` | Copy files or directories |
| `mv` | Move or rename files |
| `cat` | Display file contents |
| `find` | Search for files and directories |

## Practice Lab

Run these commands in a Linux terminal or Linux virtual machine.

```bash
pwd
ls -la
mkdir -p ~/linux-practice
cd ~/linux-practice
touch notes.txt
ls -l
```

## Expected Results

- `pwd` displays your current directory.
- `ls -la` lists directory entries, including hidden entries.
- `mkdir -p` creates the practice directory if it does not already exist.
- `cd` moves into the practice directory.
- `touch` creates `notes.txt` if it does not exist.
- `ls -l` displays the file listing.
