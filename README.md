# Linux Administration Labs

## Project Overview

This repository documents my hands-on learning journey in Linux system administration as I work toward becoming an AWS Cloud Engineer.

The exercises focus on practical command-line skills, filesystem navigation, file permissions, user and group management, and the foundations of Linux system administration.

## Learning Objectives

- Navigate the Linux filesystem using the command line.
- Create, manage, and organise files and directories.
- Understand Linux file permissions and ownership.
- Create and manage users and groups.
- Apply least-privilege principles when managing access.
- Build a foundation for system administration, troubleshooting, and cloud infrastructure operations.
