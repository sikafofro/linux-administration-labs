# Linux Administration Labs

## Project Overview

This repository documents my practical learning and exercises in Linux administration as part of my journey toward becoming an AWS Cloud Engineer.

The focus is on command-line operations, file management, permissions, process management, system services, task scheduling, and troubleshooting.

## Learning Objectives

- Navigate the Linux filesystem using the command line.
- Manage files and directories.
- Understand users, groups, and file permissions.
- Inspect and manage running processes.
- Work with system services using `systemctl`.
- Schedule recurring tasks with `cron`.
- Practise basic Bash scripting and troubleshooting.

## Skills and Commands

| Area | Commands and tools |
|---|---|
| Navigation | `pwd`, `ls`, `cd` |
| Files and directories | `touch`, `mkdir`, `cp`, `mv`, `rm` |
| File inspection | `cat`, `less`, `head`, `tail` |
| Permissions | `chmod`, `chown` |
| Processes | `ps`, `top`, `kill` |
| Services | `systemctl`, `journalctl` |
| Scheduling | `cron`, `crontab` |
| System information | `df`, `du`, `free`, `uname` |
